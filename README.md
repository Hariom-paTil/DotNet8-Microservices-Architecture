.NET 8 Microservices Architecture

This project is a Microservices-based E-Commerce application built using .NET 8.

It includes multiple independent services such as Authentication, Coupons, and API Gateway.

Currently, the project is under development. The goal is to understand how microservices communicate and work together in a real-world application.

Tech: C# | .NET 8 | SQL Server | EF Core | Ocelot
